Summary

Hey, I found a critical Reflected Cross-Site Scripting (XSS) vulnerability on your service at 34.149.12.109. The name GET parameter on the /profile endpoint is directly reflected in the HTTP response without proper HTML encoding or sanitization, allowing arbitrary JavaScript execution in the victim's browser.

Vulnerable Endpoint & Reproduction Link

Follow the reproduction link below to observe the vulnerability in action:

https://jp-ag.github.io/pi2-interview-vrp/bug_2.html

(Clicking the URL above will navigate to the reproduction proof).

Steps to Reproduce

  1. Navigate to the reproduction link above in any standard web browser.
  2. Observe that the web server reflects the unescaped name parameter directly into the page DOM.
  3. The injected JavaScript payload <script>alert(0)</script> executes immediately upon loading, triggering an alert popup with the value 0.

Impact

An attacker can craft a malicious link containing arbitrary JavaScript and distribute it to authenticated users or administrators. When visited, the script executes within the victim's session context. This can be leveraged to steal session cookies via document.cookie, perform unauthorized account actions, or redirect users to malicious domains.
